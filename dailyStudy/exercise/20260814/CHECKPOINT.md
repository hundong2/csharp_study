# 초보자 확인 단계

코드를 보지 않고 다음 질문에 한두 문장으로 답해 보세요.

- `string`과 `string?`는 무엇이 다른가요?
- `record`, `enum`, LINQ의 `GroupBy`와 `Select`는 각각 어떤 문제를 줄이나요?
- 예상 가능한 입력 오류는 Result, 저장소 장애와 취소는 예외로 다루는 이유는 무엇인가요?
- Repository, Strategy, Application Service의 책임은 각각 무엇인가요?
- Composition Root와 DI가 테스트를 쉽게 만드는 이유는 무엇인가요?
- `async`/`await`와 `CancellationToken`이 서버 운영에서 필요한 이유는 무엇인가요?
