# 초보자 확인 단계

- [ ] `string`과 `string?`의 차이를 설명할 수 있다.
- [ ] 배열, `foreach`, `if`, `enum`, record가 하는 일을 말할 수 있다.
- [ ] `async`/`await`가 CPU를 빠르게 만드는 문법은 아니라는 점을 안다.
- [ ] LINQ `OrderBy`를 사용한 이유를 설명할 수 있다.
- [ ] 예상 가능한 실패는 Result, 비정상 장애는 예외로 구분한 이유를 말할 수 있다.
- [ ] DI가 테스트 대역 교체를 쉽게 만드는 과정을 설명할 수 있다.
- [ ] Application Service, Domain Model, Repository, Strategy, Composition Root의 책임을 구분한다.
- [ ] SRP, OCP, DIP가 예제 어디에 적용됐는지 하나씩 찾는다.
- [ ] 운영 환경에서 멱등성, 동시성, 로그, 메트릭, 취소, 재시도가 필요한 이유를 안다.
