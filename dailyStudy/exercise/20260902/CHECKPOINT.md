# 초보자 검증 단계

- [ ] `var`, `new`, 문자열, 숫자 리터럴, `if`, `foreach`, 메서드 호출을 코드에서 찾을 수 있다.
- [ ] `string?`와 null 검사가 왜 필요한지 설명할 수 있다.
- [ ] `record`, `enum`, `decimal`, LINQ, `async`/`await`의 쓰임을 한 문장씩 말할 수 있다.
- [ ] Domain Model, Application Service, Repository, Strategy, Composition Root의 책임을 구분한다.
- [ ] 예상 가능한 실패에 Result를, 뜻밖의 장애에 예외를 쓰는 이유를 설명한다.
- [ ] `dotnet build`가 경고 없이 성공한다.
- [ ] 기본 실행에서 승인 1건, 수동 검토 1건, 거절 2건을 확인한다.
- [ ] 자체 테스트가 4/4 통과한다.
