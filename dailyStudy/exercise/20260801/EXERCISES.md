# 실습 문제

각 단계 후 `dotnet run -- --self-test`를 실행하세요.

1. **기초**: 빈 엔드포인트를 입력해 Result 오류를 확인하고 해당 테스트를 추가하세요.
2. **기초**: Premium 요청의 첫 실행이 `Remaining == 9`인지 검증하세요.
3. **중급**: LINQ로 사용량이 가장 큰 클라이언트를 출력하세요.
4. **중급**: `Internal` 요금제와 제한 100인 Strategy를 서비스 수정 없이 추가하세요.
5. **심화**: `(ClientId, Endpoint)`별로 별도 할당량을 저장하도록 Domain Model과 Repository를 바꾸세요.
6. **전문가**: 고정 시간 창 만료를 주입 가능한 `TimeProvider`로 구현하고 경계 시각 테스트를 작성하세요.
7. **운영**: 저장 충돌 예외에만 제한된 재시도를 적용하고, 취소와 일반 예외는 재시도하지 않도록 설계하세요.
