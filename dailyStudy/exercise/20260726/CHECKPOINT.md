# 초보자 확인 단계

코드를 보지 않고 답한 뒤 다시 실행해 확인하세요.

- `string?`와 `string`의 차이는 무엇인가?
- `if`, `foreach`, `switch` 식은 각각 어떤 결정을 표현하는가?
- record와 `init`이 변경 가능한 class보다 안전한 상황은 언제인가?
- LINQ 정렬이 처리 순서를 어떻게 표현하는가?
- `async`/`await`와 `CancellationToken`이 외부 저장소 작업에 필요한 이유는?
- 입력 오류는 Result, 인프라 장애는 예외로 다루는 이유는?
- Domain Model, Application Service, Repository, Strategy의 책임은 무엇인가?
- Composition Root에서 구현을 조립하면 테스트가 쉬워지는 이유는?
- SRP, OCP, DIP가 이 예제의 어느 부분에 나타나는가?

마지막으로 `초보자 검증 통과 (4/4)`를 확인하고, 각 통과 조건을 자기 말로 설명하세요.
