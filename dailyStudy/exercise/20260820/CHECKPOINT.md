# 초보자 확인 단계

코드를 보지 않고 다음 질문에 한두 문장으로 답하세요.

1. `string`과 `string?`는 무엇이 다른가요?
2. `record`를 장애와 배정 결과에 사용한 이유는 무엇인가요?
3. `async`/`await`가 저장소 I/O에서 유용한 이유는 무엇인가요?
4. `Result<T>`와 예외는 각각 어떤 실패에 적합한가요?
5. Repository, Strategy, Application Service의 책임을 각각 말해 보세요.
6. Composition Root에서 의존성을 조립하면 테스트가 왜 쉬워지나요?
7. 재시도, 멱등성, 취소, 로그에서 운영 환경이 주의할 점은 무엇인가요?
