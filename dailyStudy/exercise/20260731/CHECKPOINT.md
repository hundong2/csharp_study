# 초보자 검증과 짧은 복습

- [ ] `dotnet build`가 경고·오류 없이 끝난다.
- [ ] 일반 실행이 배정 결과를 출력하고 self-test가 4/4 통과한다.
- [ ] 변수, 조건문, 반복문, 메서드, enum, nullable을 한 문장씩 설명할 수 있다.
- [ ] record/불변성, LINQ, async/await의 쓰임을 설명할 수 있다.
- [ ] Result와 예외의 사용 시점을 구분할 수 있다.
- [ ] Domain Model, Application Service, Repository, Strategy의 책임을 말할 수 있다.
- [ ] DI/DIP, SOLID, Composition Root가 테스트 가능성을 높이는 이유를 말할 수 있다.
- [ ] 안정적 해시, idempotency, timeout/취소, 재시도, metric/trace, 로그 마스킹의 필요성을 말할 수 있다.
