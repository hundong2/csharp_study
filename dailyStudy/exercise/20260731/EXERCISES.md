# 실습 문제

각 단계 뒤 `dotnet run -- --self-test`를 실행하세요.

1. **기초**: 존재하지 않는 플래그 키를 입력하고 Result 오류를 확인하세요.
2. **기초**: `TreatmentPercentage`가 0~100 범위인지 검사하는 생성 규칙과 테스트를 추가하세요.
3. **중급**: LINQ로 Variant별 사용자 수를 출력하세요.
4. **중급**: 특정 사용자 목록에만 Treatment를 주는 Strategy를 추가하세요.
5. **심화**: 같은 `(FlagKey, UserId)` 배정을 중복 저장하지 않도록 Repository 조회와 Result를 설계하세요.
6. **전문가**: 플래그 설정 버전과 배정 이유를 감사 로그에 남기고, 감사 저장 실패를 재시도 큐로 넘기는 흐름을 설계하세요.
