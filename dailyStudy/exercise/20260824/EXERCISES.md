# 단계별 실습

## 1단계: 문법 확인

`E-101`의 `IsIdentityVerified`를 `false`로 바꾸고 출력 변화를 확인하세요. `bool`, enum, `if` 분기를 직접 설명합니다.

## 2단계: 정책 확장

CSV 파일의 보존기간을 12시간 단위로 표현하도록 Domain Model을 바꾸고 자체 테스트를 추가하세요. 단위가 이름에 드러나야 하는 이유도 적습니다.

## 3단계: 실패와 멱등성

같은 요청 ID에 서로 다른 계획을 두 번 저장해 두 번째가 실패하는 테스트를 작성하세요. 예상 가능한 충돌을 `Result`로 둔 이유를 적습니다.

## 4단계: 실무 설계

파일 생성 성공 후 알림 발행이 실패하는 상황을 설계하세요. Outbox 필드, 멱등 키, 재시도 상한, 파일 만료·삭제 작업, 메트릭을 표로 정리합니다.
