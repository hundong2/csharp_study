# 초보자 확인 단계

코드를 보지 않고 답한 뒤 다시 코드와 비교하세요.

1. 변수, 조건문, 반복문, 메서드는 각각 어떤 역할인가?
2. `Team`만 nullable인 이유는 무엇인가?
3. record와 `with`가 변경 가능한 객체보다 안전한 점은 무엇인가?
4. `Any`, `First`, `Count(predicate)`는 무엇을 묻는 LINQ인가?
5. `async`/`await`와 `CancellationToken`이 I/O 작업에 필요한 이유는 무엇인가?
6. 예상 가능한 입력 실패는 Result, 예상 밖 시스템 실패는 예외로 나눈 이유는 무엇인가?
7. Domain Model과 Application Service의 책임은 어떻게 다른가?
8. Repository와 Strategy를 인터페이스로 분리하면 테스트가 왜 쉬워지는가?
9. Composition Root는 어떤 구현을 선택하는가?
10. SRP, OCP, DIP가 이 코드의 어느 부분에 반영됐는가?
11. 운영 환경에서 중복, timeout, 재시도, UTC, 로그·메트릭을 어떻게 다룰 것인가?

## 완료 기준

- [ ] 일반 실행에서 장애 2건과 요약을 확인했다.
- [ ] `--self-test`가 4/4를 통과했다.
- [ ] 2단계 과제를 구현하고 테스트를 추가했다.
- [ ] 각 계층의 책임을 한 문장씩 설명할 수 있다.
- [ ] 메모리 예제와 실제 운영 구현의 차이를 두 가지 이상 말할 수 있다.
