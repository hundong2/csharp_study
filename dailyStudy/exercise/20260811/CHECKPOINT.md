# 초보자 확인 단계

- [ ] `string`과 `string?`의 차이를 설명할 수 있다.
- [ ] `foreach`와 `if`가 각각 무엇을 하는지 찾을 수 있다.
- [ ] `record`와 읽기 전용 집합이 변경 위험을 줄이는 이유를 말할 수 있다.
- [ ] LINQ가 이미 보유한 권한을 어떻게 제외하는지 설명할 수 있다.
- [ ] 예상 가능한 실패는 Result, 인프라 장애는 예외로 둔 이유를 말할 수 있다.
- [ ] Repository, Strategy, Application Service의 책임을 구분할 수 있다.
- [ ] Composition Root에서 DI가 이루어지는 줄을 찾을 수 있다.
- [ ] 운영 환경에 로그, 시간 제한, 멱등성이 필요한 이유를 한 가지씩 말할 수 있다.
