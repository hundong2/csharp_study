# 초보자 확인 단계

코드를 보지 않고 다음 질문에 한두 문장으로 답해 보세요.

- `string?`와 `string`은 무엇이 다른가요?
- `decimal.TryParse`가 사용자 입력 검증에 적합한 이유는 무엇인가요?
- `record`, `enum`, LINQ의 `Where`와 `Select`는 각각 어떤 문제를 줄이나요?
- 예상 가능한 행 오류는 `Result`, 저장소 장애는 예외로 다루는 이유는 무엇인가요?
- Repository, Strategy, Application Service의 책임은 각각 무엇인가요?
- Composition Root와 DI가 테스트를 쉽게 만드는 이유는 무엇인가요?
- `async`/`await`와 `CancellationToken`이 서버 운영에서 왜 필요한가요?

## 짧은 복습 체크리스트

- [ ] 실행 결과와 self-test 4/4를 확인했다.
- [ ] nullable 검사와 기본 문법을 코드에서 직접 찾았다.
- [ ] SRP, OCP, DIP가 적용된 위치를 말할 수 있다.
- [ ] 부분 성공, 멱등성, 배치 크기, 로그·메트릭, 재시도를 운영 관점에서 생각했다.
