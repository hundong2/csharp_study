# 실습 과제

## 1단계: 초보 검증

1. `CUSTOMER-101`의 동의 시각을 364일 전으로 바꾸고 결과가 무엇인지 확인하세요.
2. 연락 채널이 `null`인 고객이 왜 제외되는지 해당 `if` 조건을 말로 설명하세요.
3. `dotnet run -- --self-test`가 4/4인지 확인하세요.

## 2단계: 문법 연습

- `RenewalSummary`에 `TotalCount` 속성을 LINQ로 추가하고 출력하세요.
- 동의 후 300일 미만을 나타내는 별도 사유를 `switch` 식에 추가하세요.

## 3단계: 설계 연습

- VIP 고객은 350일부터 안내하는 새 Strategy를 구현하세요. 기존 서비스를 수정하지 않는 것이 목표입니다.
- 저장소가 같은 고객 ID에 다른 결과를 저장하려 할 때 실패하는 테스트를 추가하세요.

## 4단계: 실무 확장

- 연락처 원문을 로그에 남기지 않으면서 상관관계 ID를 감사 로그에 추가하세요.
