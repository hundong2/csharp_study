# 초보자 확인 단계

코드를 보지 않고 다음 질문에 한두 문장으로 답해 보세요.

- `string?`와 `string`의 차이는 무엇인가요?
- `record`와 `with` 식이 변경 실수를 줄이는 방법은 무엇인가요?
- `Where`, `OrderByDescending`, `ToArray`는 각각 무엇을 하나요?
- 예상 가능한 업무 실패는 `Result`, 비정상 장애는 예외로 나눈 이유는 무엇인가요?
- Repository, Strategy, Application Service의 책임을 각각 설명할 수 있나요?
- Composition Root에서 의존성을 조립하면 테스트가 쉬워지는 이유는 무엇인가요?
- `async`/`await`와 `CancellationToken`이 서버 운영에 왜 필요한가요?

## 짧은 복습 체크리스트

- [ ] 실행 결과와 self-test 4/4를 확인했다.
- [ ] 기본 문법을 코드에서 직접 찾았다.
- [ ] SOLID 중 SRP, OCP, DIP가 적용된 위치를 설명할 수 있다.
- [ ] 중복 실행, 로그, 메트릭, 재시도, 알림 실패를 운영 관점에서 생각했다.
