# 초보자 검증 단계

- [ ] `dotnet run`으로 위험도 3건이 출력된다.
- [ ] `dotnet run -- --self-test`가 `4/4 통과`를 출력한다.
- [ ] `string?`, `??`, `var`, `new(...)`, `enum`의 의미를 말할 수 있다.
- [ ] record를 불변 값 모델에 쓰는 이유를 설명할 수 있다.
- [ ] Repository, Strategy, Application Service, Composition Root의 역할을 한 문장씩 말할 수 있다.
- [ ] 업무 실패(Result)와 예상 못 한 기술 장애(Exception)를 구분할 수 있다.
- [ ] `CancellationToken`을 전달하는 이유와 운영 로그에 추적 ID가 필요한 이유를 설명할 수 있다.
